Steps to run Spring Microservice on Kubernetes / Docker Windows 10 Pro (example given below):

1. Start Desktop Docker (download it if not available on your machine, e.g, Docker version 26.1.4, build 5650f9b)

2. Open Command Prompt (Run as administrator) and run the following commands

3. minikube start --driver=docker (download minikube if not on your machine, eg, minikube v1.33.1 on Microsoft Windows 10 Pro 10.0.19045.6466 Build 19045.6466)

4. minikube docker-env

5. Create a folder, eg, C:\mygitrepositories\kuber_repository\kubernetesexamples\springexamples\springforkuber

6. cd C:\mygitrepositories\kuber_repository\kubernetesexamples\springexamples\springforkuber

7. Creata a java file, eg, SpringforkuberApplication.java, in a package in the above folder

8. Create a pom.xml file in the above folder

9. Run pom.xml to create springforkuber-0.0.1-SNAPSHOT.jar in the target folder of the above folder

10. Create a Dockerfile (without any extesion) in the above folder

11. docker build -t springforkuberim:1.0 .

12. Crea a personal docker hub repository on https://hub.docker.com/

13. docker login -u manumitmukund -p Mkdmkd`123 (Use your docker hub userid/pwd)

14. docker tag springforkuberim:1.0 manumitmukund/mykuberrepository:springforkuberim_1_0 (mention your docker hub repo path, eg, manumitmukund/mykuberrepository)

15. docker push manumitmukund/mykuberrepository:springforkuberim_1_0

16. kubectl create deployment springforkuberdeployment --image=manumitmukund/mykuberrepository:springforkuberim_1_0 --port=9001 (mention your docker hub repo path, eg, manumitmukund/mykuberrepository))

17. kubectl expose deployment springforkuberdeployment --type=NodePort

18. (After a few seconds) kubectl port-forward svc/springforkuberdeployment 9001:9001

19. hit url: http://127.0.0.1:9001/kuber/hello
